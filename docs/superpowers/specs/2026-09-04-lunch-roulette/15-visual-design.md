# 15. 시각 디자인

[← 인덱스](README.md)

화면 4개([07-screens.md](07-screens.md))에 입히는 시각 언어. 동작과 문구는 바꾸지 않고 겉모습만 정한다.
문구는 [08-errors.md](08-errors.md)와 07을 그대로 쓴다.

## 컨셉: 단골 도장 카드

레벨 이름(처음, 익숙, 단골, 찐단골, 집밥)이 이 앱의 정체성이다. 동네 밥집의 도장 쿠폰이 하는 말과 같다.
그래서 화면 전체를 "백반집 메뉴판과 도장 쿠폰"의 어휘로 만든다.

| 화면 요소 | 비유 | 표현 |
|---|---|---|
| 룰렛 영역 | 벽에 걸린 흰 메뉴판 | 검은 테두리 2겹의 흰 판. 굵은 고딕으로 식당 이름이 넘어가다 멈춘다 |
| 후보 3개 | 식권 3장 | 왼쪽 본문(이름, 주소) + 점선으로 나뉜 오른쪽 절취선 영역(도장) |
| 확정 | 인주 도장 | 확정된 식권 위에 빨간 원형 도장 "확정"이 찍힌다. 확정 직후에만 찍히는 움직임을 재생한다 |
| 레벨 배지 | 도장 5칸 | 찍힌 칸 수가 레벨. 빈 칸이 "다음 레벨까지 N회"를 말한다. 글자 설명은 보조 |
| 기록 목록 | 뜯어낸 식권 반쪽 더미 | 점선 괘선으로 나뉜 목록 |

대담함은 한 곳에만 쓴다: 도장 찍힘. 나머지는 흰 바탕, 검은 선, 조용한 본문이다.

## 토큰

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| paper | #FFFFFF | 바탕 |
| ink | #000000 | 글자, 테두리 |
| seal | #D62E2E | 돌리기 버튼, 도장, 오류 문구, 포커스 링 |
| seal-deep | #B3201F | 누른 상태의 돌리기 버튼 |
| muted | #6F6F6F | 주소, 보조 문구 |
| rule | #E3E3E3 | 약한 구분선 |

크림색 바탕, 테라코타 강조, 둥근 카드 그림자, 눈썹 대문자 라벨, 가운뎃점(·) 연결은 쓰지 않는다.

## 서체

| 역할 | 서체 | 크기 |
|---|---|---|
| 표시(식당 이름, 메뉴판, 화면 제목, 장소 선택) | Black Han Sans 400 | 20, 25, 32, 40px |
| 본문(그 외 전부) | IBM Plex Sans KR 400/500/700 | 13, 16, 20px |

둘 다 Google Fonts. `next/font/google`로 자체 호스팅한다. 본문 줄 간격 1.5, 표시 줄 간격 1.1~1.2. 한글은 `word-break: keep-all`.

## 레이아웃

모바일 세로 한 열. 최대 너비 480px, 좌우 여백 20px, 하단 탭 높이만큼 아래 여백. 본문은 왼쪽 정렬, 메뉴판 안 글자만 가운데 정렬.

```
┌──────────────────────────┐
│ 회사 ▾          오늘 점심 │  장소 선택(표시 서체) + 슬롯
│ ┌──────────────────────┐ │
│ │      김밥천국         │ │  메뉴판(돌리는 중) 또는 안내 문구
│ └──────────────────────┘ │
│ ┌ 식권 ────────┬───────┐ │
│ │ 김밥천국      ┆ ●●●○○ │ │  후보 식권 3장
│ │ 강남대로 123  ┆ 단골  │ │
│ └──────────────┴───────┘ │
│ ┌──────────────────────┐ │
│ │       돌리기          │ │  빨간 버튼. 화면에 하나뿐
│ └──────────────────────┘ │
│  홈     장소     기록     │  하단 탭. 현재 탭은 빨간 밑줄
└──────────────────────────┘
```

홈 상태별 룰렛 영역:

| 상태 | 메뉴판 내용 |
|---|---|
| 슬롯 밖 | "다음 룰렛은 HH:MM에 열립니다" |
| 세션 없음 | "영업 중인 식당 3곳을 뽑습니다" (07의 "안내 없음"을 이 한 줄로 바꾼다) |
| 후보 부족 | "지금 영업 중인 식당이 N곳뿐입니다" |
| 돌리는 중 | 후보 풀 이름이 80ms마다 바뀜 |
| open | 메뉴판 대신 식권 3장 |
| confirmed | 식권 1장 크게 + 도장 |

## 움직임

- 돌리기 후 메뉴판 이름 회전(07 규칙 그대로)과 확정 직후 도장 찍힘, 두 번만.
- `prefers-reduced-motion: reduce`면 둘 다 재생하지 않고 결과만 보여 준다.
- 카드 호버 효과, 화면 진입 페이드는 넣지 않는다.

## 접근성

- 돌리는 중 메뉴판은 `role="status"`로 "후보를 뽑는 중입니다"를 알리고, 바뀌는 이름은 `aria-hidden`.
- 후보 식권은 `aria-pressed`로 선택 상태를 알린다.
- 하단 탭의 현재 화면은 `aria-current="page"`.
- 포커스 링은 seal 색 3px.
- 도장 5칸은 `role="img"`에 "레벨 N 이름, 다음 레벨까지 N회"를 라벨로 준다.

## 문구

07과 08을 그대로 쓴다. 추가하는 문구는 아래뿐이다.

| 위치 | 문구 |
|---|---|
| 세션 없음 메뉴판 | 영업 중인 식당 3곳을 뽑습니다 |
| 기록 비어 있음 | 아직 기록이 없습니다. 홈에서 룰렛을 돌리면 여기에 쌓입니다 |
| 레벨 업 | 레벨 업! 이제 {레벨 이름}입니다 |
| 로그인 부제 | 지금 영업 중인 근처 식당 3곳 중에서 고릅니다 |
| 기록 날짜 | 2026년 9월 4일 점심, 회사 (가운뎃점 대신 쉼표) |
