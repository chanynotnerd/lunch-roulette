# 01. 개요

[← 인덱스](README.md)

## 목적

점심과 저녁 메뉴를 고민하지 않도록, 지금 영업 중인 근처 식당 3곳을 무작위로 뽑아 주고
사용자가 그중 하나를 고르면 기록과 레벨로 남기는 웹앱.

## 사용자

- Google 계정으로 로그인한 개인.
- 장소, 경험치, 기록은 사용자별로 분리된다. 식당 데이터만 공용이다.

## 1차 범위

- Google 로그인
- 장소 등록(이름, 주소, 반경)과 삭제
- 장소 생성 시 주변 식당과 영업시간 자동 수집
- 슬롯(점심, 저녁)당 룰렛 1세션: 돌리기, 다시 돌리기 1회, 3개 중 1개 확정
- 현재 시각 기준 영업 중 식당만 후보에 포함
- 확정 기록의 날짜별 조회
- 식당별 개인 레벨 표시(5단계)

## 1차 범위에서 제외

- 장소 수정(삭제 후 재생성으로 대체)
- 식당 수동 추가, 편집, 관리 화면(BO)
- 레벨에 따른 당첨 확률 가중치
- 팀 공유, 초대
- 알림
- 테마 설정

## 기술 스택

| 영역 | 선택 |
|---|---|
| 프레임워크 | Next.js (App Router) |
| 배포 | Vercel |
| DB, 인증 | Supabase (Postgres, Auth Google 로그인, RLS) |
| 외부 API | Google Geocoding, Google Places Text Search. 서버에서만 호출 |
| 시간대 | Asia/Seoul 고정 |

선택 이유는 [02-decisions.md](02-decisions.md)의 D2, D3, D12를 참조한다.
