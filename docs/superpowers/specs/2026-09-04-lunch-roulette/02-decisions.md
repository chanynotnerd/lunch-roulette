# 02. 결정 기록

[← 인덱스](README.md)

브레인스토밍에서 확정한 결정이다. 번호는 논의 순서다.
결정을 바꾸려면 이 파일의 해당 항목을 고치고, 영향을 받는 주제 파일을 함께 고친다.

| 번호 | 주제 | 결정 | 이유 | 관련 문서 |
|---|---|---|---|---|
| D1 | 근처 판정 | 장소 태그 방식. 장소에 연결된 식당만 후보 | 지도 API 없이 "근처"를 정의할 수 있는 가장 단순한 방법 | 04 |
| D2 | 앱 형태 | 브라우저 웹앱, Vercel 배포 | 룰렛 연출과 접근성이 좋고 서버 관리가 없음 | 03 |
| D3 | 저장소 | Supabase | 브라우저를 껐다 켜도 데이터 유지, 인증 내장 | 03, 04 |
| D4 | 인증 | Google 로그인만 지원 | 가입, 비밀번호 찾기 화면을 만들지 않아도 됨 | 06 |
| D5 | 확정 방식 | 후보 3개 중 사용자가 1개 선택 | 실제로 간 식당만 경험치를 받아 레벨의 의미가 유지됨 | 05, 06 |
| D6 | 다시 돌리기 | 세션당 1회 | 결과를 살짝 바꿀 여지는 주되 무한 반복은 막음 | 05 |
| D7 | 세션 단위 | 하루 두 슬롯(점심 11~15, 저녁 17~21), 슬롯당 1세션, 확정 시 잠금 | 날짜별 기록과 정확히 대응하고 경험치 어뷰징을 막음 | 05 |
| D8 | 슬롯 밖 시간 | 돌리기 차단, 다음 슬롯 시각 안내 | 영업시간 판정이 항상 실제 식사 시간대에 이뤄짐 | 05, 07 |
| D9 | 레벨 | 5단계 고정 테이블, 표시 전용 | 다음 레벨까지 몇 번인지 직관적. 확률 가중치는 룰렛 목적과 충돌 가능 | 05 |
| D10 | 영업시간 입력 | 요일별 개별(휴무, 오픈, 마감, 브레이크 1구간) | 수요일 휴무 같은 실제 패턴을 표현 | 04 |
| D11 | 식당 데이터 소스 | Google Places로 자동 수집 + 보정 파일. 관리 화면 없음 | 손으로 입력하는 BO를 만들지 않음 | 09, 10 |
| D12 | 데이터 소유 | 장소, 세션, 경험치는 개인. 식당은 공용 캐시 | 사용자가 만든 장소마다 식당을 자동 수집하므로 식당은 공유가 자연스러움 | 04 |
| D13 | 장소 등록 | 사용자가 앱에서 직접 등록. 등록 시 서버가 Google API 1회 호출 | 집처럼 사용자마다 다른 장소를 담기 위해 | 06, 09 |
| D14 | 영업시간 없는 식당 | 저장은 하되 후보에서 제외 | 갔는데 닫혀 있는 상황이 더 나쁨 | 05, 10 |
| D15 | 검색 방식 | Nearby Search 대신 Text Search(최대 3페이지 60개) | Nearby Search는 20개 상한에 다음 페이지가 없음 | 09 |
| D16 | 검증 순서 | 구현 전 데이터 품질 스파이크를 0번 작업으로 수행 | Google의 국내 영업시간 커버리지가 가장 큰 불확실성 | 12 |
| D17 | 식당 데이터 소스 전환 | Google 결제 계정이 정상화되지 않아 카카오 로컬 API로 전환. 카카오는 영업시간을 주지 않으므로 기본 영업시간(매일 11:00~21:00, 브레이크 없음)을 넣고 hours_source='default'로 표시하며, 실제 시간은 보정 파일로 덮어쓴다 | 2026-09-04 구현 중 Google Maps API가 "결제 미활성"으로 거부됨. D14(영업시간 없으면 제외)를 그대로 두면 후보가 0개라 앱이 동작하지 않음 | 09, 10, 12 |
| D18 | 식당 수집 확장 | 카카오 질의를 키워드 9개(음식점, 한식, 중식, 일식, 양식, 분식, 아시아음식, 패스트푸드, 술집)로 나누고, 반경 500m 초과면 2×2 rect 격자를 겹쳐 동시 5개로 호출한 뒤 id로 합친다. 장소당 중심 거리순 200개까지 저장. 반경 허용 범위는 100~1000m로 축소. 카페(CE7)는 제외. 작업 하나라도 실패하면 전체 실패. 기존 장소 재수집은 B3과 함께 | 카카오 키워드 검색은 질의당 최대 45건이라 번화가에서 가까운 45곳만 들어왔다. 비용은 없고(일 30만 회 무료, 결제 수단 없음) 2000m는 호출이 243회까지 늘어 서버 액션 시간 제한에 걸린다 | 17, 09 |
