# 07. 화면

[← 인덱스](README.md)

화면은 4개다. 모바일 세로 화면을 기준으로 만든다. 점심 직전에 폰으로 여는 상황이 가장 흔하기 때문이다.
상태 판단은 서버 응답을 그대로 따르며, 화면은 스스로 규칙을 계산하지 않는다. [03-architecture.md](03-architecture.md)

## S1. 로그인

- Google 로그인 버튼 하나.
- 로그인 상태면 홈으로 자동 이동한다.

## S2. 홈(룰렛)

상단: 장소 선택 드롭다운, 현재 슬롯 상태 문구.
가운데: 룰렛 영역. 서버가 알려 준 상태에 따라 아래 셋 중 하나를 보여 준다.

| 상태 | 표시 | 버튼 |
|---|---|---|
| 슬롯 밖 | "다음 룰렛은 HH:MM에 열립니다" | 돌리기 비활성 |
| 세션 없음(슬롯 안) | "영업 중인 식당 3곳을 뽑습니다" | 돌리기 활성 |
| open | 후보 카드 3개(이름, 주소, 도장 5칸) | 다시 돌리기(미사용 시 활성), 카드 탭 → 확정 확인 |
| confirmed | "오늘 점심: OO" 또는 "오늘 저녁: OO", 도장 5칸, 레벨업 시 축하 표시, 다음 슬롯 안내 | 없음 |

- 후보 풀이 3개 미만이면 "지금 영업 중인 식당이 N곳뿐입니다"를 보여 주고 돌리기를 비활성화한다.
- 확정 확인은 카드 탭 후 "OO으로 확정할까요?" 한 단계만 둔다.

### 룰렛 애니메이션

- 서버 응답을 받은 뒤 1.5~2초간 후보 풀 식당 이름을 빠르게 넘기다 후보 3개에 멈춘다.
- 애니메이션 중에는 모든 버튼을 잠근다.
- 후보 풀 이름은 돌리기 응답에 포함된 목록을 쓴다. 추가 요청은 없다.

## S3. 장소 관리

- 내 장소 목록. 각 항목에 이름, 주소, 반경, 연결된 식당 수.
- 장소 추가 폼: 이름, 주소, 반경(기본 500, 100~2000).
- 장소 삭제 버튼. "OO을 삭제할까요?" 확인 한 단계.
- 장소를 누르면 연결된 식당 목록: 이름, 주소, 도장 5칸, 다음 레벨까지 N회, hours가 없으면 "영업시간 정보 없음".

## S4. 기록

- confirmed 세션을 날짜 내림차순 목록으로. 날짜, 슬롯(점심/저녁), 장소 이름, 식당 이름, 확정 당시 레벨.
- 삭제된 장소는 "삭제된 장소"로 표시한다.
